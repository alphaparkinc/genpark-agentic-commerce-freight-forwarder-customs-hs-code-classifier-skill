## 🛠️ MCP Tools Exposed
- `classify_product_hs_code`: Classify product description into 6-digit WCO Harmonized Tariff Schedule code and calculate duty rate.
- `audit_tariff_engineering_savings`: Assess tariff engineering re-classification opportunities (e.g. unassembled vs assembled).
